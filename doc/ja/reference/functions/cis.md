# cis

`(cis number)`

ラジアン単位の角度 `number` における単位円上の点を返します: `(cis x)` は `e^{ix}`、すなわち `(cos x, sin x)` です。引数が実数の場合でも結果は常に複素数です。複素数の引数では原点へと減衰します: `re + i·im` の `cis` は `(e^{-im} cos re, e^{-im} sin re)` です。インタプリタと JVM はハードウェアの `exp`/`cos`/`sin` から計算し、WASM バックエンドはソフトウェア近似から導出するため、最下位桁が異なる場合があります。`(cis 0)` はすべてのバックエンドで正確に `#C(1.0 0.0)` です。

```lisp
(cis 0) ; => #C(1.0 0.0)
```
