# complex

`(complex real &optional imag)`

実部と省略可能な虚部（省略時はゼロ）から正規の複素数を返す。有理数のゼロ虚部は実数そのものに降格し、浮動小数点数のゼロは複素数のまま残る（浮動小数点数と組になった整数のゼロは `0.0` になる）。有理数の部分は浮動小数点数と組になると浮動小数点数に強制されるため、完全な有理数は両部分が有理数のときに限り完全なままになる。複素数は `#C(real imag)` と読み書きする。非実数の部分は捕捉可能な型エラーを通知する。4バックエンドすべてで動作する。

```lisp
(complex 1 2) ; => #C(1 2)
```

```lisp
(complex 1 0) ; => 1
```

```lisp
(complex 2.0 0) ; => #C(2.0 0.0)
```
