# signum

`(signum number)`

`number` の符号を示す `-1`、`0`、`1` のいずれかを、その数値型を保ったまま返します。整数または有理数の引数は整数の結果を、浮動小数点数の引数は浮動小数点数の結果 (例: `1.0`、`0.0`、`-1.0`) を返します。複素数の引数は単位ベクトル `z/|z|` を浮動小数点数で返します (`#c(3 4)` に対して `#C(0.6 0.8)`)。ゼロは自身の部分の正規化を答えます (完全な部分には `0`、浮動小数点数の部分には `#C(0.0 0.0)`)。

```lisp
(signum -5) ; => -1
```

```lisp
(signum 3.5) ; => 1.0
```

```lisp
(signum #c(3 4)) ; => #C(0.6 0.8)
```
